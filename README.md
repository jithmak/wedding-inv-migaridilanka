# 💍 Migari & Dilanka — Wedding Invitation

> A bespoke digital wedding invitation built as a single-page experience.  
> Designed, animated, and deployed for **Migari Kamburugamuwa & Dilanka Aththiligoda**

---

## 🌐 Live Site

**[View Invitation →](https://weddinginv-migaridilanka.netlify.app)**

---

## ✨ Features

- **Animated hero** — layered wave artwork with organic vertical breathing motion, floating petal particles, and expanding ripple rings
- **Twinkling star field** — procedurally generated sparkle elements across multiple sections
- **Arch section** — animated sparkles, expanding rings, name glow pulse, and a periodic shine sweep
- **Live countdown timer** — counts down days, hours, minutes, and seconds to the ceremony
- **WhatsApp RSVP** — one-tap button that opens WhatsApp with a pre-filled message
- **Google Maps embed** — venue location for Green Serenity Holiday Resort, Kurunegala
- **Scroll-triggered fade-ins** — content reveals as guests scroll using IntersectionObserver
- **Fully responsive** — optimised for mobile and desktop
